# sword-extra

Shared tower utilities for the Sword framework.

Everything here is used by more than one transport (web, socket.io, gRPC) and
lives behind a feature flag.

Built for the [Sword](https://github.com/sword-web/sword) framework:
- GitHub: https://github.com/sword-web/sword
- crates.io: https://crates.io/crates/sword
